# NovelAI Desktop

Official Windows x64 installers and signed application updates.

This repository contains release artifacts and release notes only. Application source code is maintained separately in a private repository.

## Downloads

Download installers from [Releases](https://github.com/YILING0013/nai_desktop_releases/releases).

Versions with the updater can check, download and install new releases from Settings → About. Earlier versions require one manual upgrade to enable in-app updates. Tauri update signatures are verified before installation; this is separate from Windows publisher signing.

Updates preserve the local library, models, settings and credentials. Finish ongoing generation or inference and save your work before installing.
